Transcription Dev Harness

Dev tool only. It exists only when DEV_TOOLS_ENABLED=true. Audio you submit here is sent to the transcription engines (Groq, ElevenLabs), which are third-party services. See docs/adr/0023-transcriber-interface.md.
Microphone access needs a secure context (HTTPS or localhost). Recording will fail on this address; uploading a file still works.
Log in
1. Choose
2. Record or upload a clip 0.0s
3. Transcribe
The clip is uploaded once and reused, so running both engines does not upload it twice.
