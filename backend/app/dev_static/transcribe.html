Transcription Dev Harness

Dev tool only. It exists only when DEV_TOOLS_ENABLED=true. Audio you submit here is sent to the transcription engines (Groq, ElevenLabs), and transcripts you summarize are sent to Groq or Gemini, which are third-party services. See docs/adr/0023-transcriber-interface.md and docs/adr/0025-summarization-model-choice.md.
Microphone access needs a secure context (HTTPS or localhost). Recording will fail on this address; uploading a file still works.
